# clean-android-tv-launcher
A clean-looking Android TV launcher (Home), with clean-looking weather &amp; media (Spotify, etc.) widgets (multiple looks to choose from), a dock for favorite apps, etc..

Started as work built on top of the famous https://cleanyour.tv/ | https://github.com/Gathin23/cleanyourtv , but eventually branched out to make it more feature complete without feeling bloated.
